# تطبيق الحر الأصلي – AL-HUR AL-ASLI

تطبيق Android بواجهة عربية RTL يعمل بالاتجاه الأفقي فقط على الهواتف والأجهزة اللوحية وAndroid TV. يتصل بمزوّد Xtream مصرح به، ويشمل تسجيل دخول، بثًا مباشرًا، أفلامًا ومسلسلات، تصفحًا بالتصنيفات، بحثًا، تفاصيل المحتوى ومشغل Media3.

## النسخة الحالية

- رقم الإصدار: `0.6.0` (`versionCode 6`).
- تسجيل الدخول والرئيسية والتصفح والتفاصيل ومشغل الفيديو كلها مثبتة أفقيًا.
- بعد تسجيل الدخول تظهر لوحة رئيسية بشريط اشتراك وحالة وعدد الأجهزة، وثلاث بطاقات رئيسية للقنوات والأفلام والمسلسلات، وثلاث بطاقات للاختصارات.
- تُحفظ بيانات الدخول اختياريًا بشكل مشفر محليًا عبر Android Keystore وAES/GCM.
- تُحفظ بيانات المحتوى والتصنيفات محليًا في Room. تُعرض الدفعات الأولى (40 عنصرًا تقريبًا لكل دفعة حفظ) أثناء استمرار التنزيل، ثم تضاف النتائج اللاحقة تدريجيًا؛ لا ينتظر التطبيق تنزيل القائمة كاملة لبدء العرض.
- شاشة إعدادات كاملة بدل الحوار، تشمل بيانات الاشتراك، نمط التحديث (6 ساعات/24 ساعة/يدوي)، مظهر AMOLED، حفظ الدخول المشفر، تحديث المكتبة الفوري، ومعلومات الدعم.
- قبل فتح الأقسام أو البحث الشامل، يتأكد التطبيق من توفر تصنيفات القنوات والأفلام والمسلسلات محليًا؛ وإذا لم تكن جاهزة يحاول تحميلها أولًا.
- شاشة الإعدادات المستقلة تعرض الاشتراك والأجهزة، إعداد التحديث، المظهر، حفظ الدخول، التحديث الفوري، وبيانات الدعم وتجديد الاشتراك عبر واتساب.
- شاشة الدخول تستخدم خادم المزود المثبت في التطبيق `http://bbgyxvwf.fqvpnw.com`؛ أدخل اسم المستخدم وكلمة المرور فقط. عناصر التحكم مهيأة للتنقل بأسهم الريموت وزر OK/Enter، مع إبراز العنصر المحدد.
- مشغل الفيديو يتيح تبديل الملاءمة إلى تكبير/ملء أو تمديد. يظهر زر تخطي المقدمة في أول خمس دقائق من الفيديو ويخفي نفسه بعد استخدامه مرة واحدة في جلسة التشغيل الحالية.
- أثناء المزامنة تُحفظ دفعات صغيرة من المحتوى وتُضاف إلى الشاشة فورًا؛ تُستكمل القائمة تدريجيًا من قاعدة البيانات بدل انتظار تنزيل كل العناصر قبل بدء العرض.

## فتح المشروع وبناؤه

افتح مجلد المشروع في Android Studio وثبّت Android SDK 36. أو ابنِ APK التجربة من الطرفية:

```bash
./gradlew assembleDebug
```

لتشغيل اختبارات الوحدة:

```bash
./gradlew testDebugUnitTest
```

ينتج APK في `app/build/outputs/apk/debug/app-debug.apk`. هذه نسخة Debug موقّعة بمفتاح الاختبار؛ مناسبة للتثبيت والتجربة وليست إصدارًا جاهزًا للنشر التجاري أو Google Play. رفع المتجر يتطلب إعداد توقيع Release وإنتاج AAB ومراجعة سياسات المتجر.

## الاستخدام والخصوصية

أدخل عنوان الخادم وبيانات اشتراك تملك صلاحية استخدامه. لا يتضمن المشروع حسابًا أو محتوى جاهزًا. بيانات الدخول لا تُكتب في سجلات التطبيق، ويمكن إلغاء خيار حفظ الدخول من شاشة الدخول أو الإعدادات. استخدم محتوى مرخصًا فقط.

قد تختلف حقول مدة الاشتراك والاتصالات النشطة بين مزوّدي Xtream؛ يعرض التطبيق ما يرجعه المزود، أو «غير محدد» عند غياب الحقل. تعذّر الاتصال لا يعني أن بيانات الاشتراك خاطئة بالضرورة.

## ملفات المشروع الرئيسية

- `app/src/main/java/com/alhorrtv/app/MainActivity.kt`: تسجيل الدخول واستعادة الجلسة.
- `HomeActivity.kt`: لوحة التحكم الأفقية، بيانات الاشتراك، المظهر والإعدادات.
- `Sync.kt`: حفظ المحتوى محليًا وجدولة التحديث حسب اختيار المستخدم.
- `ContentDatabase.kt`: قاعدة بيانات المحتوى والتصنيفات وسجل المشاهدة.
- `AppCore.kt`: التخزين المشفر والاتصال بالخادم والبحث والصور.
- `BrowseActivity.kt`: تصفح القنوات والأفلام والمسلسلات والتصنيفات.
- `MovieDetailActivity.kt` و`SeriesDetailActivity.kt`: تفاصيل الأفلام والمسلسلات.
- `PlayerActivity.kt`: تشغيل الفيديو.
- `REPORT_AR.md`: تقرير التنفيذ والاختبارات والقيود.
